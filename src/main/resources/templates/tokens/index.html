Claude (claude.ai, Desktop, mobile, and Claude Code signed in with your Claude account): add a custom connector with the URL https://kina.example.com/mcp and sign in when asked. Nothing to copy from this page.

Claude Code on its own: claude mcp add, then /mcp to sign in.

Access tokens

Static tokens are for scripts calling the KINA HTTP API and for Claude Code on machines without a browser (Authorization: Bearer header). New tokens are valid for 30 days. Clients connected through Claude's connector appear here as MCP: <client>; revoking one disconnects that client.
